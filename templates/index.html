    Why this tool exists
    
        
    AI can write the code — but you still get asked the fundamentals in
        interviews, and you still need to review what the AI wrote. This prototype attacks
        both problems:
    
        
      
          
    • Explain — paste any snippet (especially AI-generated code). A real AST
            analyzer detects the constructs used and explains what it is, why the syntax
            looks like that, then walks through the code statement by statement, reviews it for
            bugs/smells with concrete fixes, and can run it with plain-English error explanations.
            With your own API key you can also chat with an AI tutor about the snippet —
            it keeps the conversation and your code in context, so follow-ups actually build on
            each other.
      • 
          
    • Learn — 15 fundamentals lessons (mutability, scoping, functions, OOP,
            generators, decorators…) with annotated examples, key points and interview Q&As.
            Each lesson also has its own AI tutor chat that already has the lesson in context,
            so you can ask for a simpler explanation, another example, or to be quizzed.
      • 
          
    • Practice — 32 interview-style questions built around the classic Python
            gotchas, with instant explanations. Every question links straight back to the lesson
            that teaches it, and can hand the question to the AI tutor when you want to dig in.
      • 
        
    
        
    How the analysis works
    
        
    The explainer parses your code with Python's own ast module — no internet
        needed. A knowledge base maps each syntax construct to “what / why / example / interview
        question”. A review pass runs ~23 static checks (mutable default arguments, bare
        except, range(len(...)), late-binding closures, shared mutable class
        attributes, unsafe eval…). “Run” executes your code in an isolated subprocess
        with CPU/memory limits and a 5-second timeout.
